## RDP Nexus 1.0.0

First release of RDP Nexus, a compact floating utility that keeps a Remote Desktop session gently
active by navigating **only inside the RDP window you select**.

### Highlights

- Floating dark control panel: Start / Pause / Resume / Stop, a countdown, status reasons, tray icon.
- Keyboard navigation every 13 minutes by default (configurable):
  - **Shuffle apps**: visits every app open in the remote session in a fresh random order each round,
    never the same app twice in a row (uses the RDP client's Alt+Page Up).
  - Remote apps (Alt+Page Up / Alt+Page Down) and Browser tabs (Ctrl+Tab, Ctrl+Page Up/Down) modes.
  - Page or arrow scrolling, down / up / alternate.
- Gentle pointer movement inside the RDP client area only. It never clicks, and it pauses as soon as
  you touch the mouse, until you resume it.
- Strict input isolation: explicit RDP target, re-validation and a foreground check right before
  every atomic `SendInput`, a post-send check, and suspension on focus loss, minimize, dialog,
  disconnect, lock or screen saver.
- Per-user installer (no admin rights), portable exe, optional launch at sign-in.

### Known limitations

See the *Limitations* section of the README. In short: no API can remove the microsecond race
between checking focus and Windows delivering input; "connected" detection is a heuristic; and
Shuffle apps relies on the *Open apps* count you set, because the remote screen isn't visible to
local software.
