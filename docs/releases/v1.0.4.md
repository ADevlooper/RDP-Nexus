## RDP Nexus 1.0.4

Includes the 1.0.3 fix, which was not published on its own.

### Fixed
- **App switching did nothing in a full-screen Remote Desktop session** (1.0.3). Tested live: with
  Remote Desktop Connection's default keyboard setting, a full-screen session forwards **Alt+Tab** to
  the remote PC and passes **Alt+Page Up** through unchanged, so the remote PC ignores it. RDP Nexus
  now picks the keys the client actually forwards before every switch:
  - **Alt+Tab** / Alt+Shift+Tab when the session is full screen with the default setting, or the
    setting is *On the remote computer*;
  - **Alt+Page Up** / Alt+Page Down when it is windowed, or the setting is *On this computer*.
  The setting is read from the `.rdp` file (or `Documents\Default.rdp`); **Target → Keys** shows the
  choice. If local focus changes right after an Alt+Tab, automation suspends and that window uses
  Alt+Page Up from then on.

### New
- **Cycle through all apps** is the new default switch: VS Code → browser → Visual Studio → … and round
  again. One Alt+Shift+Tab per switch brings up the app used longest ago, so every open app is visited
  in turn with no app count to keep up to date. Verified live: four screenshots, four different apps.
- Switch options in Remote apps mode: *Cycle through all apps*, *Shuffle apps*, *Back and forth* (plain
  Alt+Tab between the last two apps), *Off*. Settings still on the old default (Shuffle apps) move to
  Cycle through all apps.
