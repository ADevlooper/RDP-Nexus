## RDP Nexus 1.0.2

### Fixed
- **RDP Nexus disappeared from the taskbar while still running.** The — button and launch at sign-in
  used to hide the panel in the system tray, and Windows 11 tucks new tray icons into the hidden
  overflow (^), so the app looked gone. The panel now **minimizes to the taskbar by default** and keeps
  its taskbar button. Clicking that button restores it.

### Added
- **Options → Minimize to: Taskbar / System tray.** Choose *System tray* for the previous behaviour; the
  first time the panel hides there, a notification tells you where to find it.
- A safety check every 2 seconds restores the panel's taskbar button if Windows or Tk ever drops it.
