## RDP Nexus 1.0.3

### Fixed
- **App switching did nothing in a full-screen Remote Desktop session.** Tested live: with Remote
  Desktop Connection's default keyboard setting (*Apply Windows key combinations: Only when using the full
  screen*), a full-screen session forwards **Alt+Tab** to the remote PC and passes **Alt+Page Up** through
  unchanged, so the remote PC ignores it. Earlier versions only ever sent Alt+Page Up.

### Changed
- Before every switch RDP Nexus now picks the keys the RDP client actually forwards:
  - **Alt+Tab** / Alt+Shift+Tab when the session is full screen with the default setting, or the
    setting is *On the remote computer*;
  - **Alt+Page Up** / Alt+Page Down when it is windowed, or the setting is *On this computer*, because
    Alt+Tab would switch your *local* apps there.
- The setting is read from the `.rdp` file the client was started with, or `Documents\Default.rdp`.
  **Target → Keys** shows which keys are used and why.
- Safety net: if local focus changes right after an Alt+Tab, automation suspends and that RDP window is
  switched to Alt+Page Up for good.
- The Remote apps switch options are now *Shuffle apps*, *Next app* and *Previous app*.

### Verified
- Live, full-screen `mstsc` session: Test now chose Alt+Tab and the remote app switched; local focus
  stayed on the RDP window and no key was left pressed.
