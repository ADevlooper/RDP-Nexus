## RDP Nexus 1.0.1

### Fixed
- **Switching apps inside a windowed Remote Desktop Connection session did nothing.** In 1.0.0 the log
  showed *Switched remote app* but the remote session stayed on the same app. Version 1.0.0 sent every
  shortcut as one zero-delay burst. RDP Nexus now presses keys one at a time with human-like timing:
  Alt is held, Page Up is tapped with pauses between taps, then Alt is released.

### Added
- **Test now** (Keys tab): runs one switch + scroll immediately. Click inside the RDP window and keep
  still; the result appears in the status line and the Log tab. There's no need to wait for the countdown.
- **Key timing** (Options tab): *Normal* or *Slow* for laggy connections.

### Safety
- Every individual key event is now preceded by a foreground check, a user-activity check and a
  held-key check. If focus moves, you touch the keyboard or mouse, or you pause/stop mid-shortcut, every
  key RDP Nexus holds is released at once and the shortcut is abandoned, so no key is left stuck.
